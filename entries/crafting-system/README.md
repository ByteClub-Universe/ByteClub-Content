# Crafting System

## Overview

Crafting is the ultimate "I made this" mechanic. You gather resources, combine them according to recipes (or discover recipes), and create something new. It gives players ownership over their gear and progression. When it clicks, it's addictive. When it's tedious, it's inventory management simulator.

## Core loop

1. Player gathers raw materials from the world
2. Player discovers or knows recipes
3. Player combines materials at a crafting station
4. New item/weapon/tool is created
5. Player uses crafted item, feels accomplished
6. Cycle repeats with better materials

## Crafting archetypes

### Recipe-based (Minecraft)
- **Fixed recipes**: Known combinations, predictable outcomes
- **Discovery element**: Some recipes found through experimentation
- **Grid-based**: Placement matters (Minecraft's 3x3 grid)
- **Blueprint-based**: Schematics unlock recipes

### Freeform (Minecraft redstone, Garry's Mod)
- **Player creativity**: No fixed recipes, build what you want
- **Physics-based**: Components interact realistically
- **Emergent**: Complex systems arise from simple rules
- **No ceiling**: Creativity is the only limit

### Tiered progression (Terraria, Monster Hunter)
- **Material tiers**: Better materials = better gear
- **Linear upgrade paths**: Iron → Steel → Mythril → etc.
- **Branching options**: Same material, different item types
- **Set bonuses**: Crafting matching sets gives extra power

### Skill-based (some MMOs)
- **Crafting skill**: Level up crafting separate from combat
- **Quality variance**: Same recipe, quality depends on skill
- **Masterwork**: Rare critical successes create special items
- **Specialization**: Focus on one crafting discipline

## Design dimensions

### Resource economy
- **Abundant**: Resources are plentiful, crafting is easy
- **Scarce**: Resources are rare, every craft matters
- **Gated**: Certain resources only in late-game areas
- **Trading**: Can buy resources from other players/NPCs

### Complexity
- **Simple** (Minecraft): One material type per recipe
- **Moderate** (Terraria): Multiple materials + station requirements
- **Complex** (Monster Hunter): Specific parts from specific monsters
- **Deep** (Path of Exile): Crafting IS the endgame

### Player expression
- **Cosmetic variation**: Same stats, different looks
- **Stat customization**: Choose which stats to prioritize
- **Unique effects**: Special properties from rare materials
- **Functional difference**: Crafted items behave differently

### Discovery
- **Known recipes**: All recipes available from the start
- **Discovered**: Find recipes through exploration/experimentation
- **NPC-taught**: Learn from crafting NPCs
- **Community**: Share recipes with other players

## Anti-patterns

- **Tedious gathering**: If collecting resources isn't fun, crafting isn't either
- **Too many steps**: 15-step recipes feel like work, not play
- **No meaningful choice**: If there's one "best" recipe, crafting is pointless
- **Inventory bloat**: Too many material types clog inventory
- **Unclear recipes**: Players shouldn't need a wiki for basic crafting

## References

- Minecraft: The game that proved crafting is a mainstream mechanic
- Terraria: Crafting depth that rewards exploration
- Monster Hunter Rise: Monster parts as crafting materials = brilliant loop
- Valheim: Crafting tied to progression and base building
