# Skill Tree

## Overview

Skill trees are the "who do I want to be?" mechanic. They visualize character progression through branching paths of abilities and stats. The best ones create meaningful choices at every node. The worst ones are just stat increases with extra steps. Path of Exile's tree is so big it needs its own zip code.

## Core loop

1. Player earns experience/points
2. Player allocates points in skill tree
3. Character gains new abilities/stats
4. Build takes shape based on choices
5. Player experiments with different paths

## Tree architectures

### Linear progression (Assassin's Creed Valhalla)
- **Straightforward**: Simple unlock sequence
- **Low decision weight**: Most choices are obvious
- **Accessible**: Easy to understand for all players
- **Limited build diversity**: Everyone ends up similar

### Branching paths (Borderlands 3)
- **Multiple branches**: Different playstyles per branch
- **Deep specialization**: Go deep in one branch for power
- **Cross-branch**: Some builds mix branches
- **Respec available**: Can redo choices

### Web/web (Path of Exile)
- **Massive network**: Thousands of nodes
- **Extreme diversity**: Near-infinite build possibilities
- **High complexity**: Requires planning and knowledge
- **Intimidating**: New players overwhelmed

### Compact trees (Hades)
- **Small but meaningful**: Few choices, each impactful
- **Boon-based**: Skills come from gods, tree enhances them
- **Run-specific**: Different each run
- **Accessible**: Easy to experiment

### Weapon/stance-based (Devil May Cry)
- **Per-weapon trees**: Different trees for different weapons
- **Playstyle evolution**: Unlock new combos and moves
- **Skill expression**: Trees enhance player skill
- **Style-based**: Trees encourage stylish play

## Design dimensions

### Choice weight
- **Minor**: Small stat increases, not impactful
- **Moderate**: New abilities that change gameplay
- **Major**: Build-defining choices that change everything
- **Meta**: Choices that affect how you approach the game

### Respec options
- **Free respec**: Can redo anytime (encourages experimentation)
- **Limited respec**: Costs resources, but possible
- **No respec**: Permanent choices (high stakes)
- **Partial**: Can respec some nodes but not all

### Transparency
- **Full info**: See all nodes before committing
- **Progressive reveal**: Unlock visibility as you progress
- **Hidden nodes**: Some abilities are surprises
- **Community-driven**: Players share tree knowledge

### Build identity
- **Clear archetypes**: Tank, DPS, healer paths
- **Emergent builds**: unexpected combinations work
- **Meta-dominant**: Some builds clearly better
- **Balanced**: Multiple viable paths

## Anti-patterns

- **Illusion of choice**: If one path is clearly best, choices are meaningless
- **Too complex**: If players can't understand the tree, they won't engage
- **Too simple**: If choices are obvious, there's no decision-making
- **No impact**: If skill points don't change how you play, why bother
- **Respect penalty**: If respeccing is too expensive, players avoid experimenting

## References

- Path of Exile: The most complex skill tree in gaming (and that's the point)
- Borderlands 3: Class-specific trees with clear identities
- Hades: Compact trees that enhance build variety per run
- Assassin's Creed Valhalla: Accessible but less impactful trees
