# Time Manipulation

## Overview

Time manipulation lets you bend the rules of reality. Rewind mistakes, slow-mo for precision, or freeze everything except yourself. It's the ultimate power fantasy and puzzle mechanic rolled into one. Prince of Persia made "undo" a core gameplay feature, and games have been obsessed with time ever since.

## Core loop

1. Player encounters a challenge requiring precise timing
2. Player activates time manipulation ability
3. Time slows/stops/rewinds
4. Player acts with advantage (more time to think/aim)
5. Time resumes, player sees consequences of actions

## Time mechanics

### Slow motion (Bayonetta, Max Payne)
- **Witch Time**: Dodge at last second, world slows
- **Bullet time**: Aim in slow-mo for precision shots
- **Adrenaline**: Slow-mo activates during intense moments
- **Resource-limited**: Slow-mo meter depletes with use

### Rewind (Prince of Persia, Life is Strange)
- **Undo death**: Rewind to before you died
- **Rewind puzzle**: Reverse object states to solve puzzles
- **Limited rewind**: Number of rewinds per section
- **Full rewind**: Unlimited but costs resources

### Pause/stop (Superhot, Zelda)
- **Time moves when you move**: Unique take on time control
- **Stasis**: Freeze one object while world continues
- **Timestop**: Brief freeze for planning
- **Environmental**: Freeze specific elements (water, enemies)

### Time loops (Outer Wilds, Deathloop)
- **Full loop**: Time resets after set period
- **Knowledge persistence**: Keep information, not items
- **Branching paths**: Explore different timeline options
- **Meta-progression**: Learning IS the progression

## Design dimensions

### Scope of control
- **Self only**: Only player character is affected
- **Environmental**: Affects objects and enemies
- **Universal**: Everything in the world is affected
- **Selective**: Can target specific objects/enemies

### Resource management
- **Meter-based**: Depletes with use, recharges over time
- **Cooldown**: Can use again after waiting
- **Limited charges**: X uses per level/checkpoint
- **Unlimited**: Always available, balanced by other costs

### Puzzle integration
- **State preservation**: Objects remember their state when rewound
- **Causality chains**: Actions in slow-mo have consequences at normal speed
- **Multi-timeline**: Compare states across time manipulation
- **Environmental puzzles**: Time affects water, fire, electricity

## Anti-patterns

- **Overpowered**: If time manipulation solves everything, there's no challenge
- **Confusing**: Multiple time states can be mentally taxing
- **Performance heavy**: Rendering multiple timelines is expensive
- **No consequence**: If time manipulation has no cost, it's not a mechanic
