# Interactive Tutorial

## Overview

The golden rule: if your tutorial has a skip button, it's bad. Interactive tutorials teach by doing — you learn to jump by jumping, you learn to shoot by shooting. No walls of text, no boring cutscenes. Just the game letting you figure it out through play.

## Core loop

1. Player encounters a new mechanic in a safe environment
2. Player experiments with the mechanic through interaction
3. Game provides feedback (visual, audio, or state change)
4. Player internalizes the mechanic through repetition
5. Mechanic is then tested in a real gameplay context

## Design dimensions

### Teaching method
- **Show, don't tell** (Portal): Place an element, let the player figure it out
- **Guided discovery** (Half-Life 2): Hints and nudges, not instructions
- **Forced practice** (Super Mario Bros): First level IS the tutorial
- **Opt-in** (Celeste): Optional demos for advanced techniques

### Failure tolerance
- **Safe spaces** (Portal): Can't die in early test chambers
- **Graceful failure** (Astro Bot): Failing is funny, not punishing
- **Real stakes** (Dark Souls): Learn or die, no hand-holding
- **Progressive** (Hollow Knight): Start safe, gradually increase difficulty

### Information delivery
- **Environmental** (Portal): Signs, placement, level design communicates rules
- **Diegetic** (Half-Life 2): NPCs explain through dialogue naturally
- **Non-diegetic** (some games): UI popups, tooltips (least preferred)
- **Hybrid** (Astro Bot): Mix of environmental and UI-based teaching

### Pacing
- **One concept at a time**: Don't introduce jump AND shoot AND dash simultaneously
- **Spacing**: Introduce concept, let player practice, then build on it
- **Recall**: Revisit old mechanics in new contexts later

## Anti-patterns

- **Text walls**: Nobody reads them. Ever. Stop writing them
- **Pop-up overload**: Too many tooltips = visual noise = players ignore all of them
- **Forced tutorials on replay**: Returning players shouldn't be forced through basics
- **Mechanic dumping**: Introducing 5 mechanics at once and expecting players to remember
